## 🚀 Getting Started

### Prerequisites

-   Android Studio
-   A compatible JDK
-   Android SDK components required by the project

### Installation

**1. Clone the repository**

``` bash
git clone https://github.com/foxylayzz777/Foxy-Chat-For-Friends.git
```

**2. Open the project**

Open Android Studio and select the cloned project folder.

**3. Sync Gradle**

Allow Android Studio to download dependencies and synchronize the
project.

**4. Run the application**

Connect a compatible Android device or start an Android emulator, then
run the app from Android Studio.
